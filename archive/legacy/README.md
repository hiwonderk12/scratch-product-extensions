# 旧格式资产

`dist/` 保存旧版本 `.mpext` 文件的原始字节，供兼容研究、回归和旧版本追溯。部分历史共享包携带两软件的内容或旧卡片，它们不属于当前分支的新格式有效发行集合，不据此开放产品支持。

`product-extension-registry.json` 是旧渠道发布配置，仅用于查阅既有地址，不是本分支的发布入口。

原扁平源码、旧 catalog 和完整 WonderCode 迁移基线可从保留的 `main` / `wondercode` Git 历史追溯。维护时不得覆盖旧版本、将归档包标为新类包，或直接让旧客户端读取当前开发中的 catalog。

新格式资产按独立模块、profile 和版本发布；其配置、兼容索引和包的生成方法以[开发手册](../../docs/development.md)为准。
