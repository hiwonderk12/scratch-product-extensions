# 拓展库开发文档

面向熟悉 Git、TypeScript 和 Python 的积木及课程开发人员。

## 阅读顺序

1. [仓库说明](../README.md)：当前产品包、版本和导入方式。
2. [产品包维护手册](development.md)：作者源码、修改入口、生成检查与合并发布。
3. 各产品目录中的 `docs/README.md`：产品固件接口、参数和代码生成约束，例如 [AiNova 入门版](../products/ainovab/docs/README.md)。

## 文档约定

- 公开资料说明如何开发和维护，以实际源码/工具支持为准；未实现的 API 或命令不写成现成功能。
- 新模块和产品提供中文说明，其他语言按需要补充；翻译不能改变参数标识和菜单实际值。
- 产品说明维护源码位置、使用方式、参数/端口、生成结果与兼容约束。
- 目录中不存放执行日志、阶段计划、内部代码审阅、对话交接、本机绝对路径或单轮验收统计。
- CLI、作者 SDK 和 Skill 的用法应随实际工具版本更新，共用同一份开发规则。
