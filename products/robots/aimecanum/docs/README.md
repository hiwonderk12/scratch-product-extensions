# AI机甲麦轮车拓展包

本目录提供 AI机甲麦轮车的图形化积木和 Python 代码生成源码。

## 安装

按[原生接口](../../../../docs/native-api.md)标准编译并打包 `robots/aimecanum`，在配套客户端“用户拓展”导入 ZIP 后点“加载”。新类包尚未进入正式远端发行渠道。

不要下载 GitHub 自动生成的 Source code 压缩包，它不是可安装的拓展包。

## 版本

拓展包使用语义化版本号，保留旧教案 RGB 灯编号字段。升级前检查元数据版本及对应 Release 的更新说明和兼容信息。

## 源码说明

- `metadata.json`：产品元数据与原生入口。
- `src/index.ts`：59 个积木、控件、就近菜单、分组及集中 i18n 配置和内联 Python。

`messages` 按语言集中维护文案，积木通过 `context.t(key)` 引用；`product.name` 与卡片名称同源。简体中文、英文、繁体中文、韩文均提供完整 key 配置，参数名和菜单实际值不翻译。普通修改主要在同一个 index 完成；仅有独立职责的复杂 Python 才另建资源文件。
